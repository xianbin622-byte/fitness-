# 骨骼映射表（草稿）

面向：**微信小程序 + Three.js / glTF**，用**身体测量数据**驱动人模比例变化。  
说明：不同素材的**骨骼命名可能不同**（Mixamo、Ready Player Me、自绑骨等），下表用**常见层级名**，落地时需在代码里做**名称映射表**（`实际骨骼名 → 逻辑部位`）。

---

## 1. 思路：没有固定「标准人」时怎么变

- 先定一套 **参考人**（仅用于算比例，可改）：例如身高 **H₀ = 170 cm**，并配一组 **参考围度**（胸/腰/臀/臂/腿等，可按性别各一套或统一一套「中性参考」）。
- 用户每次有测量：**身高 H**，以及各围度 **C_胸、C_腰、C_臀、…**（单位 cm）。
- 对每个要驱动的部位，算 **缩放系数**（示例，可按产品调）：
  - **纵向（身高）**：`s_height = H / H₀`，多用于 **整骨链条长度** 或 **根节点统一缩放**（二选一，勿重复乘）。
  - **围度（粗细）**：`s_某部位 = C_某部位 / C_某部位_参考`（或再加体脂、性别修正），多用于 **该段骨骼在「横截面」上的 scale X/Z**（人站立时通常 **Y 为身高方向**）。

这样不依赖「固定维度」，只依赖 **当前值 / 参考值** 的比值。

---

## 2. 测量项 → 建议驱动的骨骼/区域

| 测量项（业务） | 建议作用的骨骼/节点（逻辑名） | 缩放建议（常见 T-Pose，Y 向上） | 备注 |
|----------------|--------------------------------|----------------------------------|------|
| **身高** | `Hips`（根）或整条 **腿 + 脊柱** 链 | **统一**：`scale.multiplyScalar(s_height)` 在根或分腿骨/脊椎骨乘长度；或只拉长 `Spine* / LeftUpLeg / RightUpLeg / LeftLeg / RightLeg` 的 **Y** | 根整体缩放最简单；分骨拉长更自然但易穿模，要限幅 |
| **胸围** | `Chest` / `UpperChest` / `Spine2` 附近胸廓 | **X、Z** 略放大（`s_胸`），**Y 少动或不動** | 女模若与乳房 Mesh 分离，可只调胸骨+乳房挂点 |
| **腰围** | `Spine` / `Spine1`（腹部段） | **X、Z**：`s_腰`；可略混一点 `Hips` 上沿 | 腰腹常合并视觉，需和「臀围」分配比例避免重复放大 |
| **臀围** | `Hips` | **X、Z**：`s_臀` | 臀宽主要在此；注意与大腿根衔接 |
| **大臂围** | `LeftArm` / `RightArm` | **X、Z**：`s_臂` | 左右对称同步 |
| **小臂围**（若有数据） | `LeftForeArm` / `RightForeArm` | **X、Z**：`s_小臂` | 无数据时可按大臂比例估算 |
| **大腿围** | `LeftUpLeg` / `RightUpLeg` | **X、Z**：`s_大腿` | |
| **小腿围** | `LeftLeg` / `RightLeg` | **X、Z**：`s_小腿` | |
| **肩宽**（若有） | `LeftShoulder` / `RightShoulder` 或 `Clavicle` 类 | **X**：左右肩间距 | 无数据时可用胸围间接推 |

**头/颈**：一般不跟围度强绑定；除非产品要「头大身小」Q 版，再单独调 `Neck`、`Head`。

## 3. 参考围度（草稿数值，可整表替换）

仅作 **比例分母**，不是医学标准。

| 部位 | 参考值（cm，示例） |
|------|-------------------|
| 胸围 | 95 |
| 腰围 | 80 |
| 臀围 | 95 |
| 大臂围 | 32 |
| 大腿围 | 55 |
| 小腿围 | 36 |

性别：可各一套参考，或同一套再乘 **性别系数**（如女腰略细等）。

## 4. 系数到骨骼的简化公式（草稿）

设参考身高 `H₀`，参考围度 `R_胸、R_腰、…`；用户测量 `H、C_胸、C_腰、…`。

```
s_height = clamp(H / H₀, 0.85, 1.15)          // 示例限幅，防极端
s_胸     = clamp(C_胸 / R_胸, 0.85, 1.20)
s_腰     = clamp(C_腰 / R_腰, 0.85, 1.20)
s_臀     = clamp(C_臀 / R_臀, 0.85, 1.20)
s_臂     = clamp(C_臂 / R_臂, 0.85, 1.15)
s_大腿   = clamp(C_大腿 / R_大腿, 0.85, 1.15)
s_小腿   = clamp(C_小腿 / R_小腿, 0.85, 1.15)
```

- **身高**：应用到 **腿骨 + 脊椎** 的 **Y 缩放**（或根节点 **uniform** 之一），不要与下面围度 **同一骨骼重复乘两次**。
- **围度**：对该段骨骼 **`scale.x`、`scale.z`** 乘 `s_某`（或 `sqrt(s_某)` 若希望周长近似线性），**尽量少动 Y**，避免腿看起来像被拉长两次。

---

## 5. 实现顺序建议（给程序/美术）

1. 导入 GLB，在 Three 里打印 `scene.traverse` 列出**全部骨骼名**，填一张 **「逻辑名 ↔ 实际名」** 对照表。  
2. 先只接 **身高 + 腰围 + 臀围**，调顺再加大臂、大腿、小腿。  
3. 每帧或数据变更后：`updateMatrixWorld(true)`，必要时限制单骨缩放上下界。  
4. 女性胸围产品策略若与男不同：可在映射里 **女胸用固定参考** 或 **独立 Morph**，与业务一致即可。

## 6. 与当前仓库的关系

- 业务侧已有：**身高、体重、体脂、腰围、臀围、胸、臂、大腿** 等（小腿可估算）。
