# 需求说明（结构化）

## 1. 项目目标

面向中国健身私教场景，提供微信小程序双端：

- **会员端**：选教练、看可约时间、预约/取消、看身体数据与趋势、看课程与饮食建议、看上课记录。
- **教练端**：维护会员、设置可约时间、关闭某日、录入身体数据、闪记、生成并确认总结与建议。

## 2. 角色与账号

- 用户注册时选择 **会员** 或 **教练**，数据库 `users.role` 区分；注册与登录使用 **邮箱验证码**（MVP：服务端内存验证码 + 可选 SMTP；生产配置发信）。
- 会员需 **选择并绑定教练** 后，才出现在该教练的会员列表中。

## 3. 预约

- 教练创建可预约 **时段**（支持固定模板与自定义）。
- 支持 **关闭某一天**（全天不可约）。
- 同一时段仅 **一名会员** 可预约成功（防并发：唯一约束 + 事务）。
- **取消**：距开课时间 **≥1 小时** 可取消；**<1 小时** 不可取消（**仅后端规则不足，须服务端强校验**）。

## 4. 身体数据

- 教练录入：性别、年龄、身高、体重、体脂、各围度、骨骼肌、备注、记录日期。
- 会员查看列表与 **折线图** 趋势；**体型展示** 第一版为伪 3D/轮廓组件，预留升级。

## 5. 课程与闪记

- 每节课对应 **课程记录**：问题点、动作明细（重量/次数/组数）、语音 URL、总结、下次建议、饮食建议。
- **闪记 / 课后笔记**：快速录入要点；教练笔记页使用 **微信同声传译插件** 将语音转为文字（不上传录音文件）。
- **自动生成**：当前为 **本地规则引擎**（不依赖外网大模型），生成总结草稿与建议；教练可编辑后确认。

## 6. 非目标（MVP）

- 高精度 3D 扫描、全自动营养配餐、完整支付与营销体系。
