# 微信小程序上线步骤（简版）

按顺序做；**后端 HTTPS + 公众平台域名** 与 **上传代码** 缺一不可。

---

## 一、前提条件

1. 已有 **微信小程序账号**（[微信公众平台](https://mp.weixin.qq.com/)）并完成主体信息（个人或企业按你资质）。
2. 本地 **`project.config.json`** / **`miniprogram/project.config.json`** 里的 **`appid`** 改为你的 **正式 AppID**（不要用长期 `touristappid` 真上线）。
3. 后端已部署到 **公网 HTTPS**（见下文），且域名已备案（若要求 HTTPS 大陆节点等，按微信当年规则）。

---

## 二、后端（API）先能公网访问

1. 将 `server` 部署到云服务器 / PaaS（如任意支持 Node 的环境），监听 **HTTPS**（可用 Nginx 反代 + 证书）。
2. 在服务器上配置 **`server/.env`**：`DATABASE_URL`、`JWT_SECRET`（强随机）、`PORT`、`PUBLIC_BASE_URL`（你的 API 对外根地址，如 `https://api.你的域名.com`）。
3. 浏览器访问：`https://你的API域名/health` 应返回 JSON `ok: true`。

---

## 三、微信公众平台配置「服务器域名」

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → **开发** → **开发管理** → **开发设置** → **服务器域名**。
2. **request 合法域名**：填你的 API 根，**不要**带路径，例如：  
   `https://api.你的域名.com`  
   （须 HTTPS，须与证书匹配；子域名要单独加。）
3. 若使用 **上传文件、下载文件**（本项目的录音上传等）：同样配置 **uploadFile**、**downloadFile** 合法域名（可与 request 同域或 OSS 域名）。
4. 保存。若域名未备案或证书错误，会校验失败。

---

## 四、改小程序里的 API 地址

1. 打开 **`miniprogram/config/runtime.js`**（本项目已拆分环境配置）。
2. 修改：
   - `USE_PROD_API: true`
   - `PRODUCTION_API_BASE: "https://api.你的域名.com"`
3. 保持 `DEVELOPMENT_API_BASE` 不变，方便后续本地调试继续可用。
4. 重新编译、真机预览，确认请求不再被域名拦截。

---

## 五、隐私 / 类目（审核必看）

1. 登录公众平台 → **设置** → 基本设置 / 服务类目：选择与你业务一致的 **类目**（如生活服务、工具等，以平台为准）。
2. 按微信要求填写 **用户隐私保护指引**、**收集信息说明**（涉及手机号、身体数据等）。

---

## 六、上传代码与提审

1. 打开 **微信开发者工具**，导入本项目（根目录含 `project.config.json`）。
2. 确认 **AppID** 为正式小程序 AppID。
3. 菜单 **上传**：填写版本号、项目备注 → 上传成功。
4. 登录公众平台 → **管理** → **版本管理** → 找到刚上传的版本 → **提交审核**。
5. 按审核表单填写说明、截图；等待审核通过。
6. 审核通过后 → **发布**。

---

## 七、上线后

- 用户使用的是 **正式版**；开发者工具里的「不校验合法域名」**仅本机生效**。
- 后续改代码：重复 **上传 → 提交审核（若需）→ 发布**，或仅对已发布版本做「灰度」等（按平台能力）。
